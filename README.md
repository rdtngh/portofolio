# Personal Portfolio Website

## Deskripsi Project

Website portofolio pribadi ini dibuat dengan HTML, CSS, dan JavaScript murni untuk menampilkan profil, fokus area, keterampilan, dan kontak. Website ini dirancang dengan tampilan clean, responsive, serta mendukung dark mode dan animasi ringan.

## Tujuan Project

- Menyajikan profil personal dan keterampilan secara profesional
- Menampilkan fokus area yang relevan dengan minat dan kompetensi
- Meningkatkan kemampuan front-end tanpa menggunakan framework
- Menyediakan dokumentasi dan persiapan deployment GitHub Pages

## Fitur Utama

- Hero section personal dengan foto profil
- Navbar sticky dan responsive
- About section yang dirapikan
- Focus Area section
- Skills section dengan badge
- Contact section dengan tautan klikable
- Dark mode dengan penyimpanan preferensi lokal
- Animasi fade-in saat scroll
- Desain responsive untuk desktop, tablet, dan mobile

## Teknologi yang Digunakan

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages

## Struktur Folder

```
personal-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    └── cv/
```

- `index.html` untuk struktur utama halaman
- `style.css` untuk tampilan, layout, warna, dan responsive design
- `script.js` untuk dark mode, menu mobile, smooth scroll, dan animasi
- `README.md` untuk dokumentasi project

## Cara Menjalankan Project Secara Lokal

1. Clone repository
2. Masuk ke folder project
3. Buka file `index.html` langsung di browser
4. Atau gunakan Live Server di Visual Studio Code

Contoh perintah:

```bash
git clone https://github.com/rdtngh/portofolio.git
cd portfolio
```
